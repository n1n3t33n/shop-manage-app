# 🏪 Shop Manage App

Application Java de gestion multi-boutiques.

## 📦 Architecture
- **server/** - Serveur central API
- **client-boutique/** - Application de gestion boutique
- **client-user/** - Application de recherche client
- **shared/** - Code commun entre modules
